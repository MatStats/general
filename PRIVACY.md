# Privacy Policy

## KB Link Fetcher

**Last updated:** 2026-01-22

KB Link Fetcher does not collect, store, transmit, or share any personal data.

### Data collection
- No personal information is collected.
- No browsing history is stored.
- No analytics, tracking, or profiling is performed.

### How the extension works
The extension runs entirely locally in the user’s browser and is activated only through explicit user interaction (such as clicking the extension icon or selecting a menu option).  
When activated, it temporarily scans the content of the active webpage to identify publicly visible identifiers such as DOIs or PubMed IDs. These identifiers are used solely to construct a search query to the Royal Danish Library’s search system.

### Data sharing
- No data is transmitted to third parties.
- No data is sold, transferred, or shared.
- No external services or remote code are used.

### Permissions
Requested browser permissions are used strictly to enable the core functionality of the extension and are not used for monitoring user behavior or collecting data.

### Affiliation
This extension is not affiliated with, endorsed by, or officially supported by the Royal Danish Library.

### Contact
If you have questions about this privacy policy, please contact the developer via the project’s repository page.
